# 外部支付接口测试指南

## 概述

本指南帮助开发者测试和调试外部支付接口，确保订单创建流程正常工作。

## 增强的日志功能

我们已增强了外部支付接口的日志输出，现在包含：

### 请求前日志
- 🚀 调用前状态提示
- 🌐 完整的请求详情（URL、方法、请求头、请求体）
- 🔍 参数详细说明和验证
- ⏱️ 超时设置信息

### 成功响应日志
- ✅ 成功状态标识
- 📋 订单创建成功信息
- 💰 支付信息详情（订单ID、金额、状态等）

### 错误处理日志
- ❌ 失败状态标识
- 📛 详细的错误信息和类型
- ⏰ 超时错误专项分析
- 📡 响应信息（状态码、数据、头信息）
- 🔢 错误代码和消息详情

## 环境配置检查

### 微信开发者工具设置
1. **关闭域名校验**（开发环境）
   - 打开微信开发者工具
   - 点击右上角"详情"按钮
   - 在"本地设置"中勾选"不校验合法域名"
   - 这样可以临时绕过域名白名单限制

2. **确保开发服务器运行**
   - 运行 `npm run dev:weapp` 启动开发服务器
   - 确保编译成功，无语法错误

### 域名白名单配置

#### 开发环境
- 临时关闭域名校验即可测试
- 不需要配置正式域名

#### 生产环境
- 需要在微信公众平台配置以下域名：
  - `https://therianclouds.mynatapp.cc` - 开发环境接口域名
  - `https://crystal.quant-speed.com` - 生产环境接口域名

## 测试建议

1. **使用微信开发者工具进行测试**
   - 确保网络连接正常
   - 查看控制台输出，观察详细的请求和响应信息
   - 注意订单创建流程中的每个步骤

2. **检查关键日志输出**
   - 外部支付接口调用前的请求详情
   - 成功响应的订单信息
   - 失败时的错误详情和响应数据

3. **验证订单数据完整性**
   - 确认主订单创建成功
   - 检查外部订单ID是否正确生成
   - 验证金额和描述信息准确无误

## 常见错误排查

### NETWORK_ERROR 超时错误（最常见）

**表现**: 请求超时，控制台显示 "请求超时，请检查网络连接"

**根本原因**: 微信小程序域名安全策略拦截
- 请求根本没到达服务器（`externalError.response` 为 undefined）
- 这是微信小程序的安全机制，不是网络问题
- 所有未配置在微信白名单的域名都会被拦截

**立即解决方案**:

#### 🚀 开发环境（30秒解决）
1. 打开微信开发者工具
2. 点击右上角 "详情" 按钮
3. 在 "本地设置" 中勾选 ✅ **"不校验合法域名"**
4. 重新编译小程序

#### 🏭 生产环境
1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 进入 "开发" → "开发管理" → "开发设置"
3. 配置服务器域名：
   ```
   request合法域名：
   ├─ https://therianclouds.mynatapp.cc  (开发环境)
   └─ https://crystal.quant-speed.com    (生产环境)
   ```

**日志特征**:
```
❌ === 创建外部支付订单失败 ===
📛 错误信息: {type: "NETWORK_ERROR", message: "请求超时，请检查网络连接"}
🔍 错误详情:
  ├─ 错误类型: Object
  ├─ 错误消息: 请求超时，请检查网络连接
  ├─ 错误堆栈: undefined
⏰ 超时错误分析:
  ├─ 请求URL: https://therianclouds.mynatapp.cc/api/payment/create
  ├─ 超时时间: 10000ms (10秒)
  ├─ 建议: 检查网络连接或增加超时时间
  ├─ 域名配置: 确保已配置request合法域名
  └─ 微信小程序: 在开发者工具中勾选"不校验合法域名"
```

**重要提醒**: 
- ✅ 这是域名配置问题，不是代码问题
- ✅ 接口测试工具成功证明服务器正常
- ✅ 主订单创建不受影响，只有外部支付接口失败
- ✅ 开发环境勾选"不校验合法域名"立即解决

## 验证配置方法

1. **检查控制台输出**
   - 应该看到"🚀 正在调用外部支付接口..."日志
   - 请求详情应该完整显示
   - 成功时显示"✅ === 外部支付订单创建成功 ==="

2. **测试步骤**
   - 添加商品到购物车
   - 进入结算页面
   - 点击"创建订单"
   - 观察控制台日志输出

3. **预期结果**
   - 主订单创建成功
   - 外部支付订单创建成功（或失败但不影响主流程）
   - 页面正常跳转到支付页面

## 注意事项

- 外部支付接口失败不会影响主订单创建流程
- 5秒超时设置避免接口阻塞主流程
- 所有错误都会被详细记录，便于调试
- 开发环境可以临时关闭域名校验进行测试
