# 设计保存功能

## 功能概述

用户可以保存自己的水晶手串设计，并在"我的设计"页面查看、加载和管理这些设计。

## 主要改进

### 1. UI优化
- ✅ 移除顶部"千山水晶DIY" bar，让画布更突出
- ✅ 扩大画布尺寸（半径从120rpx扩大到180rpx）
- ✅ 画布高度从30vh增加到45vh，最大600rpx
- ✅ 添加"保存设计"按钮（位于清空设计和加入购物车之间）

### 2. 设计保存功能
- ✅ 保存当前设计到本地
- ✅ 自动计算设计属性（价格、重量、长度、珠子数量）
- ✅ 支持自定义设计名称
- ✅ 按更新时间排序

### 3. 我的设计页面
- ✅ 展示所有保存的设计
- ✅ 显示设计预览（珠子缩略图）
- ✅ 显示设计信息（名称、珠子数量、价格、保存时间）
- ✅ 点击设计可加载到DIY页面继续编辑
- ✅ 支持删除设计

### 4. 个人中心集成
- ✅ 添加"我的设计"入口（💎图标）
- ✅ 位于"我的订单"上方

## 技术实现

### 数据结构

```typescript
interface SavedDesign {
  id: string
  name: string
  bracelet: Bracelet
  properties: BraceletProperties
  thumbnail: string // 预留：设计缩略图
  createdAt: number
  updatedAt: number
}
```

### 服务层
- `designService.ts` - 设计服务接口
- `mockDesignService.ts` - Mock实现（使用本地存储）

### 状态管理
- `useDesignStore.ts` - Zustand store
  - `saveDesign()` - 保存设计
  - `loadDesigns()` - 加载设计列表
  - `getDesignById()` - 获取单个设计
  - `updateDesign()` - 更新设计
  - `deleteDesign()` - 删除设计

### 页面
- `pages/designs/index.tsx` - 我的设计列表页
- `pages/diy/index.tsx` - DIY页面（添加保存功能）
- `pages/profile/index.tsx` - 个人中心（添加入口）

## 用户流程

### 保存设计
1. 在DIY页面设计手串
2. 点击"保存设计"按钮
3. 设计自动保存到本地
4. 显示保存成功提示

### 查看设计
1. 进入"我的"页面
2. 点击"我的设计"
3. 查看所有保存的设计

### 加载设计
1. 在"我的设计"页面
2. 点击某个设计
3. 自动跳转到DIY页面
4. 设计已加载到画布

### 删除设计
1. 在"我的设计"页面
2. 点击设计的"删除"按钮
3. 确认删除
4. 设计被移除

## 数据存储

当前使用本地存储（localStorage）：
- Key: `mock_saved_designs`
- 格式: JSON数组
- 持久化: 永久保存（除非清除缓存）

## 注意事项

1. 设计保存在本地，清除缓存会丢失
2. 暂未实现缩略图生成功能
3. 设计名称默认为"设计 N"
4. 按更新时间倒序排列
